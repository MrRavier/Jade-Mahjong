# Proveniência dos ativos

- `jade_palace.png`: arte original gerada para este projeto em 31/08/2026; palácio celestial 16-bit, sem texto ou marcas.
- `jade_emperor_sheet.png`: seis poses originais do Imperador de Jade geradas para este projeto em 31/08/2026.
- Peças e molduras: 42 sprites determinísticos produzidos em tempo de execução por `Godot/scripts/tile_art.gd`, com paleta jade, ouro, vermelhão e marfim. O protótipo anterior em `PixelArt.cs` foi preservado, mas não entra na build de produção.
- `Corte de Jade`: composição original, rascunhada com Midify e sintetizada no próprio jogo.
- `Press Start 2P`: fonte distribuída sob SIL Open Font License 1.1; hashes e origem oficial estão registrados em `Godot/THIRD_PARTY_ASSETS.md`.

Nenhum ativo de banco de imagens é necessário para a execução.
